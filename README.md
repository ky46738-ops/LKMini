## 🌱公開種子定位

LKMini 是 🥃老K系統的可擴充公開根與安全公開模組入口。

- 🪪本體身分（Identity）決定「是誰」。
- 🪞顯影（Projection）是同一本體在不同世界的合法外觀。
- 🧭定位器（Locator）回答目前去哪裡找到公開本體或顯影。
- ♾️回推鏈（ReverseChain）由顯影回到來源、本體與 LKMINI。
- 📖公開說明書是入口顯影，不是第二本體。
- 📚必要核心是最低保護集合，不是公開內容上限。
