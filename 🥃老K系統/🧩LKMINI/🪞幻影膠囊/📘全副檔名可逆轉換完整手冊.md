# 📘全副檔名可逆轉換完整手冊

## 唯一出口

所有副檔名的原本架構、轉換器、逆向器、封裝器與格式知識統一歸入：

`06｜⭐️素材庫／🧬融合引擎／唯一出口`

其他區域依既有系統設定供應入口、說明、Runtime、驗證、零件、樣式、快照、自動化與唯一真相，不建立第二出口。

## 共通正向流程

來源原件
→ ORIGINAL原始位元唯讀保存
→ MagicBytes／MIME／副檔名／Identity辨識
→ 可掛載容器安全解包至MOUNT
→ 內容索引與逐件SHA256
→ 解析／零件化／Projection
→ SNAPSHOT_ZIP
→ MANIFEST／LOCATOR／SHA256SUMS／ReverseChain
→ 06融合唯一出口
→ OUTPUT
→ ReadBack

## 共通逆向流程

SNAPSHOT_ZIP
→ ZIP／CRC／Manifest／SHA256SUMS驗證
→ ORIGINAL原件取回
→ 原名、ByteSize、SHA256驗證
→ RESTORE
→ A=A

## Apple

`.pages`、`.numbers`、`.key`：原包保持Identity；ZIP相容時掛載；依IWA／XML／APXL等真實內部結構分流；HTML／XLSX／CSV／TSV／JSON／PNG／PDF皆為Projection，不取代Apple原件。

`.ipa`、`.app`、`.dmg`、`.pkg`、`.plist`、`.shortcut`：依MagicBytes與真實容器格式分流，不一律改名ZIP；原生簽章、安裝、匯入、啟動與真機ReadBack由相符Apple裝置端完成。

## Web／文字

`.html`、`.css`、`.js`、`.json`、`.md`、`.svg`：保存原件、結構驗證、Projection建立、原件位元回航。

## 壓縮／封裝

`.zip`、`.rar`、`.7z`、`.tar`、`.iso`：依真實MagicBytes與可用解包工具處理；原件永遠保存在ORIGINAL。

## Linux／Windows

`.deb`、`.exe`、`.dll`、`.msi`：保存原件與結構索引；原生重建、簽章與執行由相符平台工具驗證。

## 媒體

`.mp4`、`.mov`、`.png`、`.jpg`、`.mp3`：原件保存；顯影與轉碼屬Projection；有損轉換不宣稱位元可逆。

## 無副檔名

以MagicBytes、Manifest、Locator與Identity辨識，不以副檔名決定本體。

## 固定回推

來源 → 06融合唯一出口 → 🪞幻影膠囊 → 🧩LKMINI → A=A
